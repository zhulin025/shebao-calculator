# 知社保 · 社保与退休计算器

本地网页应用，覆盖大陆27座省会/自治区首府及4座直辖市，可切换普通职工、公务员、灵活就业身份。

在线访问：https://shebao.liuwa.xyz

公开源码：https://github.com/zhulin025/shebao-calculator

## 打开

```bash
cd '/Users/zhulin/Documents/ChatGPT/New project 2/shebao'
npm run dev
```

访问 http://localhost:4175 。无需安装依赖，无在线托管、账户或数据上传。页面通过本地 HTTP 加载城市 JSON，所以请使用服务器打开，而非直接双击 HTML。

## 功能

- 当前月个人/单位养老、医保、失业、工伤、职业年金及其他已录入费用。
- 基数上下限约束，灵活就业缴费档位。
- 按出生年月计算2025年起的渐进式延迟退休，纳入2030—2039最低缴费年限增长。
- 提前/延迟退休情景；公务员默认依法及时退休；年限不足按连续延缴情景计算。
- 按月积累养老个人账户、职业年金账户与未来个人养老支出。
- 退休首月基础养老金、个人账户养老金、手填过渡待遇、职业年金估算及物价折算。
- 视同年限、历史平均指数、账户余额、医保退休门槛和费用手工录入。
- 会话内3方案对比、Markdown测算单导出、打印、城市筛选与公开来源链接。

## 数据与边界

数据快照：2026-10-12。`data.js`提供基础数据，`city-extra.json`提供11城2026修订，`medical-extra.json`提供首批医保研究，追加文件补充其他城市。每城包含年份、出处和核验状态，二级转载不标为官方核验。

养老通常使用个人8%/单位16%，灵活20%但个人账户只计8%。机关职业年金个人4%/单位8%，另行积累与领取。实际地方参保类别、费用补贴和征收取整需自行核对。

医保与养老基数分别处理。未知基数/费率保留空值，显示“待补充”；存在未知项目或未核验附加险时，只显示“已知项目小计”。手动模式可按实际核定账单填写完整个人、单位费用。医保达到养老最低年限后不会自动免缴；退休医保累计与本地实缴等条件须另核。

初始输入为演示数据，养老计发基数初始以缴费参照月工资作为情景代理，不冒充城市已公布计发基数。准确测算应录入实际计发基数、个人账户、历史指数和核定的视同及过渡权益。未来工资/上下限/计发基数以同样增速变化，未来缴费指数保持不变，年利率换算为月复利，月末入账。

非整岁退休时，以现行表的相邻整岁计发月数给出估算区间，不自动插值。超过70岁或低于40岁时须补入核定计发月数。计发月数及未来政策均可能变化。职业年金税前按账户/计发月数估算，发完为止；基本养老金待遇不能因此理解为只有该月数的寿命。

未来个人养老支出仅包含起始月至预计办退之间养老个人费用。到龄不足年限后按个人20%延缴情景，机关年金在延缴期间不继续假设单位缴入；不自动判断一次性补缴情形。既往已到龄时停止待遇预测，不推断已领取状态。

跨城市退休领取地、特殊工种、病退、干部特殊规则、现已退休人员待遇、居民养老、住房公积金、税费、未来调待和社保补贴不在本工具自动计算范围内。
